# ISO 27001:2022 — 12 项安全检查覆盖率参考

## 范围说明

本脚本的 12 项检查仅覆盖 ISO 27001:2022 Annex A **技术控制（A.8）** 的少部分项。  
**整体覆盖率约 9%（8/93 控制项）。** 适用于日常安全基线巡检，不能替代正式合规审计。

---

## 使用建议

```
日常巡检            → 12 项安全检查（足够）
内部合规审计        → 需补充：物理巡检 + 文档审核 + 流程访谈
ISO 27001 认证准备  → 需完整的差距分析 + SoA 文件 + 风险处理计划
```
