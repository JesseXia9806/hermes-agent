# 数据分析方法论框架

基于数分琪琪酱的9大分析模型，为Jesse Xia的IT管理分析工作提供系统化框架。

## 🎯 核心原则

**数据分析 ≠ 做图表**
- 发现问题 → 拆解结构 → 定位卡点 → 解释原因 → 验证业务动作
- 先判断问题，再选择模型
- 多个模型组合使用

## 📊 9大分析模型框架

### 模型1: 对比分析 (Benchmark Analysis)
**用途**: 判断数据是否达标、是否改善、与目标差距
**应用场景**:
- 系统性能对比（当前vs历史、目标vs实际）
- 网络流量对比（峰值vs平均、异常vs正常）
- 服务器资源使用率对比

**执行步骤**:
1. 确定对比维度（时间、空间、目标）
2. 收集对比数据
3. 计算差异和变化率
4. 判断是否达标/改善

**示例**: Zabbix监控数据对比，VMware存储使用率趋势分析

---

### 模型2: 驱动分析 (Driver Analysis)
**用途**: 识别问题的拐点、周期、驱动因素
**应用场景**:
- 系统故障时间点分析
- 网络流量异常波动分析
- 服务器负载周期性变化

**执行步骤**:
1. 绘制时间序列图
2. 识别异常点和拐点
3. 分析周期性规律
4. 寻找驱动因素

**示例**: eHR系统审批效率变化分析，Zabbix告警时间分布分析

---

### 模型3: 结构分析 (Composition Analysis)
**用途**: 找出"结果是谁构成的"
**应用场景**:
- IT资产结构分析（各类型设备占比）
- 网络流量来源分析
- 服务器资源消耗分析

**执行步骤**:
1. 定义分类维度
2. 计算各部分占比
3. 识别主要贡献者
4. 分析结构变化

**示例**: VMware虚拟机分布分析，Zabbix监控主机类型统计

---

### 模型4: Pareto分析 (80/20法则)
**用途**: 识别问题优先级，找出关键少数
**应用场景**:
- 系统故障频率分析
- 网络设备告警分析
- 服务器性能瓶颈分析

**执行步骤**:
1. 按问题类型/严重性分类
2. 计算各类别频率/影响
3. 排序找出前20%问题
4. 解决这20%问题获得80%改善

**示例**: Zabbix问题严重性分布分析，VMware存储空间不足设备排序

---

### 模型5: 漏斗分析 (Funnel Analysis)
**用途**: 逐层计算转化率，找到损失最严重的环节
**应用场景**:
- 网络数据包传输分析
- 系统处理流程分析
- 审批流程效率分析

**执行步骤**:
1. 定义漏斗各层级
2. 计算各层级转化率
3. 识别损失最大的环节
4. 分析损失原因

**示例**: eHR审批流程各环节时间分析，网络丢包率分析

---

### 模型6: 同期群分析 (Cohort Analysis)
**用途**: 判断新获得的用户/设备质量变化
**应用场景**:
- 新部署设备稳定性分析
- 新用户行为分析
- 系统升级后性能变化

**执行步骤**:
1. 定义同期群（按时间、批次等）
2. 追踪各群体表现
3. 对比不同时期群体
4. 分析质量变化趋势

**示例**: 新部署VMware虚拟机稳定性分析，新加入Zabbix监控设备表现

---

### 模型7: RFM分析 (Recency, Frequency, Monetary)
**用途**: 识别高价值/意向用户或设备
**应用场景**:
- 设备使用频率分析
- 系统访问活跃度分析
- 资源消耗价值分析

**执行步骤**:
1. 定义R(最近使用)、F(使用频率)、M(价值/消耗)
2. 为每个维度打分
3. 组合RFM分数
4. 识别高价值群体

**示例**: VMware虚拟机使用活跃度分析，Zabbix监控设备重要性分类

---

### 模型8: 归因分析 (Attribution Analysis)
**用途**: 缩小原因范围，识别可能的影响因素
**应用场景**:
- 系统故障原因分析
- 性能下降原因分析
- 网络问题根因分析

**执行步骤**:
1. 列出可能的原因
2. 收集相关数据
3. 分析相关性
4. 缩小原因范围

**⚠️ 重要提醒**: 相关关系 ≠ 因果关系

---

### 模型9: 实验验证 (A/B Testing)
**用途**: 验证假设，判断改动是否有效
**应用场景**:
- 系统配置变更效果验证
- 网络优化方案效果验证
- 新功能部署效果验证

**执行步骤**:
1. 制定假设
2. 设计实验（A/B组）
3. 执行实验
4. 收集数据
5. 分析结果
6. 验证假设

**示例**: FortiGate配置变更效果验证，网络优化方案A/B测试

## 💡 使用建议

1. **从简单开始**: 选择1-2个最相关的模型先尝试
2. **组合使用**: 多个模型组合使用效果更好
3. **验证结果**: 相关性分析后需要通过实验验证因果关系
4. **持续改进**: 根据分析结果调整方法论
5. **记录经验**: 将成功的分析方法记录到技能中
