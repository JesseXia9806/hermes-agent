# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: Title — Author](https://example.com)
  Use for: what aspect of teaching this covers.

## Wisdom (Communities)

- [r/subreddit](https://reddit.com/r/subreddit)
  Use for: when to consult this community.
```

## Rules

- **High-trust only.** Prefer primary sources, recognised experts, peer-reviewed work.
- **Annotate every entry.** A bare link is useless in three months.
- **Group by Knowledge / Wisdom.**
- **Surface gaps explicitly.** Write a `## Gaps` section if no good resource exists.
- **Prune ruthlessly.** Remove resources that turned out to be wrong or off-mission.
- **Record community preferences.** Note if the user opted out of communities.
